📐 시스템 아키텍처

👤 담당 역할

1

이미지 생성 엔진 구축

CUDA 기반 병렬 처리 커널을 직접 설계하고 구현하여 초대형 BMP 이미지를 고속으로 생성했습니다.

2

고속 압축 & 최적화

GPU/CPU 선택형 nvTIFF 압축 처리를 구현하고, 대용량 처리를 위한 메모리 사용을 최적화했습니다.

3

비동기 파이프라인

RabbitMQ를 활용한 비동기 작업 큐 아키텍처를 설계하여 시스템 안정성을 확보했습니다.

4

실시간 스트림 구현

SSE(Server-Sent Events)를 통해 작업 진행률과 완료 상태를 실시간으로 스트리밍했습니다.

5

REST API 개발

대시보드 모니터링 및 이미지 생성/압축 이력 관리를 위한 전용 API를 개발했습니다.
